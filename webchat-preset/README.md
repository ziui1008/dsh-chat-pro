# 网页版模式

给 DeepSeek Harness 加一个「网页版」会话预设，让一次会话发给模型的东西和 chat.deepseek.com 基本一致。

## 它做了什么

| | 普通会话 | 网页版模式 |
|---|---|---|
| 系统提示 | 6,367 字符，20 段（18 段是工具用法和工程纪律） | 一行身份说明 |
| 工具 | 39 个，约 39,000 字符的 schema | 0 个 |
| 每轮前导 | 工作目录、沙箱策略、审批策略、技能目录，约 5,400 字符 | 无 |
| 模型看到的消息 | 系统提示 + 5 条前导 + 你的话 | 一行身份 + 你的话 |

## 用法

新建会话时，在会话标题下方的预设选择器里选「网页版」。之后这个会话里没有工具、没有文件读写，就是纯聊天。

## 边界

- 这个模式里模型**不能**读写文件、不能跑命令、不能上网。要干活就换回 `standard` 或 `cordis` 预设。
- 修好这一点需要另做插件（模式切换 + 保留部分工具），不在本包范围内。
- 没有压缩（compaction），超长对话到上下文上限会报错。开新会话即可。

## 为什么不是插件代码

DSH 的 agent preset 本身就是"一次会话里给模型什么"的声明。这个包只声明一个预设行，因此没有 JavaScript、没有依赖、没有构建步骤。
